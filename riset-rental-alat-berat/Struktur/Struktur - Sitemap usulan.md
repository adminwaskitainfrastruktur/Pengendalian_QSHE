# Sitemap usulan

Dasar: lima halaman umum (home, services, about, equipments, contact) dari [[Ref - Marketplace dan studi akademik]], diperluas dengan temuan lain.

1. **Beranda**: hero + [[Fitur - Form permintaan penawaran (RFQ)]], kategori unit, "Cara Sewa", testimoni, [[Fitur - CTA WhatsApp]]
2. **Armada** (katalog): [[Fitur - Katalog dan filter unit]] → [[Struktur - Halaman detail unit]]
3. **Layanan**: sewa dengan/tanpa operator, jangka pendek/panjang
4. **Area layanan**: [[Fitur - Area layanan dan SEO lokal]]
5. **Tentang**: profil, legalitas, keselamatan
6. **Kontak**: form, peta, WhatsApp

Referensi tata letak: [[Ref - Template Machima]], [[Ref - Template Equipo]].
