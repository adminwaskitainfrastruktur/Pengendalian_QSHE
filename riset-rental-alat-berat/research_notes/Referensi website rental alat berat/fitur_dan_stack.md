## 1. Software rental-management/booking: apa yang ada, harga, kecocokan untuk rental kecil Indonesia

### Takeaway
Software Barat (Booqable, EZRentOut, Rentman, Point of Rental, Wynne RentalMan) harganya dalam USD dan umumnya tanpa lokalisasi Indonesia (pajak, IDR, WhatsApp, VA); Wynne/Point of Rental tidak mempublikasikan harga dan tampaknya terlalu berat untuk rental kecil. Opsi lokal yang terkonfirmasi hanya ERP HashMicro (konten vendor) dan banyak aplikasi skripsi/akademik; tidak ditemukan produk SaaS rental alat berat Indonesia yang terpublikasi harganya.

### Cited Findings
- **Booqable** (SaaS booking/inventori; USD): sumber berbeda memberi nama dan harga paket berbeda. Software Advice: Essential $29/bln (tahunan) atau $35 (bulanan), Pro $79/$95, Premium $249/$299, semua dengan produk, pesanan, pelanggan tanpa batas [pihak-3] — [Software Advice](https://www.softwareadvice.com/scm/booqable-profile/). PricingSaaS (2026) mencantumkan skema lain: Start $29, Grow $69, Scale $149, Custom $349 [pihak-3] — [PricingSaaS](https://pricingsaas.com/companies/booqable); pengumuman harga baru resmi ada di [Booqable blog](https://cdn1.booqable.com/blog/introducing-new-pricing) dan [help center](https://help.booqable.com/articles/2508419-pricing-plans) (isi tidak terbaca; hanya muncul di hasil pencarian). Konflik nama/harga antar sumber belum terselesaikan. Uji coba gratis 14 hari dilaporkan pihak ketiga.
- Booqable mendukung perhitungan harga berdasarkan durasi, hari dalam seminggu, dan aturan tanggal, serta harga bertingkat multi-hari (contoh vendor: $80/hari untuk 1 hari, $70/hari untuk >3 hari) [vendor-mkt] — [Booqable blog](https://booqable.com/blog/essential-online-booking-features). Vendor juga mengklaim kalender ketersediaan real-time membuat pelanggan lebih mungkin menyelesaikan booking (klaim pemasaran, tanpa data).
- **EZRentOut** (SaaS asset/rental tracking): Capterra/Software Advice mencantumkan Essential $59, Growth $399, Premium $499, Enterprise custom; pengguna/lokasi tambahan berbayar; trial gratis tanpa kartu kredit [pihak-3] — [Capterra](https://www.capterra.com/p/134914/EZRentOut/). TrustRadius mencantumkan $49,98 / $134,97 / $224,95 per bulan (diskon 10% tahunan) dan SoftwareConnect $79–$349, jadi angka saling bertentangan — [TrustRadius](https://tr-web.dev.trustradius.com/products/ezrentout/pricing); [SoftwareConnect](https://softwareconnect.com/go/ezrentout-review-1fbc5). Blog vendor tentang kalender ketersediaan: [EZRentOut blog](https://blog.ezrentout.com/using-the-availability-calendar-with-equipment-rental-software/).
- **Point of Rental**: tidak mempublikasikan harga lengkap; satu situs perbandingan menyebut perkiraan awal ~$150–300/bln (satu sumber saja) [pihak-3]. Positioning: cocok untuk operator rental SMB hingga menengah; mencakup reservasi, inventori, pengiriman, penagihan tanpa overhead implementasi ERP — [Field Service Software, ulasan 6 Jul 2026](https://fieldservicesoftware.io/comparisons/point-of-rental-vs-wynne-rentalman/); [daftar terbaik, 24 Jul 2026](https://fieldservicesoftware.io/best-equipment-rental-software/).
- **Wynne Systems RentalMan**: harga custom enterprise, tidak dipublikasikan; digambarkan sebagai ERP rental purpose-built untuk armada alat berat enterprise, dengan logika kontrak rental mendalam dan penjadwalan maintenance — sumber sama [Field Service Software](https://fieldservicesoftware.io/comparisons/point-of-rental-vs-wynne-rentalman/); perbandingan dari vendor di [wynnesystems.com/compare](https://wynnesystems.com/compare) (isi tidak dibaca).
- **Rentman**: berorientasi event/AV (crew app, penjadwalan crew dan transport, biaya proyek); G2 menyebut harga masuk $19/bln untuk 1 power user, rating 4,5/5 dari 27 ulasan [pihak-3] — [Capterra Rentman](https://www.capterra.com/p/144616/Rentman/pricing/); [G2 compare](https://www.g2.com/compare/rentman-vs-yo-rent).
- **Rentle**: berbasis komisi tanpa biaya tetap (komisi dasar 1,45% dari pendapatan yang diproses lewat platform + biaya pemrosesan pembayaran), target ski/sport rental; hanya 2 rating di TrustRadius (bobot lemah) [pihak-3] — [TrustRadius compare](https://tr-web.dev.trustradius.com/compare-products/rentle-vs-yorent).
- **Yo!Rent**: dua produk bernama mirip. Yang di Software Advice adalah marketplace rental multi-vendor dari FATbit (lisensi sekali bayar, tanpa trial) — [Software Advice](https://www.softwareadvice.com.au/software/182635/yo-rent). Portal "YoRent" alat berat adalah produk lain; tidak ditemukan harganya.
- **RentalPoint**: manajemen rental event (penawaran, e-sign, template dokumen, dashboard mobile); harga tidak dipublikasikan, ulasan sangat sedikit — [GetApp](https://www.getapp.co.uk/software/2080410/rentalpoint).
- **Opsi Indonesia**: HashMicro menawarkan ERP/software rental alat berat (penjadwalan, kinerja alat, biaya, pemeliharaan) dan software manajemen rental umum (aset, ketersediaan, pesanan, kontrak, deposit, pembayaran); sumber adalah blog vendor sendiri sehingga perbandingannya tidak netral dan harga tidak ditemukan — [HashMicro: 9 Software Rental Alat Berat 2026](https://www.hashmicro.com/id/blog/software-rental-alat-berat-terbaik/); [HashMicro manajemen rental](https://www.hashmicro.com/id/software-manajemen-rental).
- Studi kasus akademik di Indonesia (bukan produk): aplikasi web sewa excavator HK Equipment, Sragen (pemesanan sebelumnya via SMS/WhatsApp/telepon/tatap muka; skripsi UMS 2026) — [UMS eprints](https://eprints.ums.ac.id/144968/); PT Kris Jaya Perkasa, Prabumulih — [Telkom Univ.](https://openlibrarypublications.telkomuniversity.ac.id/index.php/appliedscience/article/download/11390/11247/22160); CV Aditya Karya (PHP/MySQL) dan lainnya di [hasil pencarian ini](https://eprints.uniska-bjm.ac.id/10440/).
- Plugin WooCommerce untuk rental (alternatif murah): EbeRent (gratis), MOLU Equipment Booking Lite (model berbasis permintaan untuk mesin/lift, booking dikonfirmasi manual lalu pelanggan menerima penawaran), Booking and Rental Manager for WooCommerce (gratis), Bookings for WooCommerce (Plugin Republic, berbayar). RentMe Woo ditandai belum diuji pada 3 rilis WordPress terakhir; Ekiprent dijual lewat listing "nulled" (hindari) — [WordPress.org plugin](https://wordpress.org/plugins/booking-and-rental-manager-for-woocommerce/); [Plugin Republic](https://pluginrepublic.com/?p=2241503); [Barn2](https://barn2.com/blog/woocommerce-rental-product/).

### Inferences
- Untuk rental kecil Indonesia, kandidat "beli" paling rasional untuk back-office ialah tool ringan (Booqable/EZRentOut, ratusan USD/tahun) atau ERP lokal (HashMicro, perlu kuotasi). Wynne/Point of Rental kemungkinan berlebihan dan tanpa dukungan lokal (inferensi, tidak ada sumber yang menyebut ketersediaan di Indonesia).
- Untuk heavy equipment, model sewa yang umum (per hari/bulan, operator, mobilisasi) tidak otomatis cocok dengan tool "booking ala penyewaan alat event"; sebagian besar harga sebenarnya lewat penawaran (RFQ). Maka website fase 1 lebih tepat sebagai katalog + RFQ, dengan back-office di spreadsheet/tool ringan.
- Pembuatan sendiri (build) fitur transaksi penuh (kalender, kontrak, invoice) adalah investasi besar; layak dibeli/diintegrasi dahulu, dibangun kemudian bila volume jelas.
- Kemungkinan dukungan bahasa Indonesia, IDR, PPN, dan e-Faktur di produk-produk Barat rendah; ini harus dikonfirmasi per vendor (tidak ada sumber yang mengonfirmasi).

### Gaps
- Halaman resmi harga Booqable, EZRentOut tidak terbaca (host diblokir); harga bertentangan antar agregator.
- Tidak ada harga resmi Point of Rental, Wynne, RentalPoint, HashMicro, Rentman paket penuh.
- Tidak ditemukan SaaS rental alat berat khusus Indonesia dengan harga publik; belum dicari secara spesifik: Odoo Rental (komunitas Indonesia), Accurate, Jurnal/Mekari, Kledo, dan marketplace rental lokal.
- Status Booqable/EZRentOut mendukung IDR, bahasa Indonesia, atau payment gateway lokal: tidak terverifikasi.
- G2/Capterra review bersifat umum; tidak ada ulasan khusus pengguna di Indonesia.

## 2. Fitur website yang paling berdampak pada konversi B2B rental alat berat

### Takeaway
Tidak ditemukan studi independen terkontrol untuk RFQ, WhatsApp, kalender ketersediaan, atau kalkulator tarif pada rental alat berat; bukti yang ada anekdotal dan bersumber vendor. Rekomendasi aman: RFQ pendek + tombol WhatsApp dengan pesan terisi otomatis, lalu A/B test sendiri dengan metrik rasio permintaan penawaran dan waktu respons pertama.

### Cited Findings
- Studi kasus vendor: perusahaan rental mesin kompak Brasil (Lokmax) menghubungkan percakapan WhatsApp sales ke HubSpot; vendor melaporkan waktu penawaran turun dari 24–48 jam ke <3 jam (satu perusahaan, tanpa grup kontrol) [vendor-mkt] — [Eazybe case study](https://eazybe.com/case-studies/lokmaxltda).
- Artikel CRO untuk dealer alat: pengunjung sering keluar di formulir permintaan penawaran meski trafik sudah dibayar; berisi saran umum pengujian, tanpa hasil terukur [vendor-mkt] — [Scube Marketing](https://www.scubemarketing.com/blog/cro-tactics-equipment-dealers-rfq-leads).
- Vendor CRM WhatsApp mengklaim peningkatan konversi 3x dalam 6 bulan pada merek perlengkapan olahraga B2B (industri berbeda, self-reported) [vendor-mkt] — [ChatArchitect](https://www.chatarchitect.com/news/whatsapp-crm-for-b2b-strategies-for-increasing-conversion-rates).
- Aplikasi quote Shopify menawarkan opsi form multi-langkah, WhatsApp, atau telepon dengan harga disembunyikan; hanya klaim fitur, tanpa data konversi — [Shopify app listing](https://apps.shopify.com/request-a-quote-hide-price-sb).
- Kalender ketersediaan: VEVS menjelaskan opsi kalender per-unit, kalender umum, atau keduanya, tampilan bulanan atau harian — [VEVS](https://www.vevs.com/equipment-rental-software/reservation-system.php); Texada punya tampilan kalender tarif — [Texada KB](https://help.texadasoftware.com/knowledge/403/use-rate-calendar-view-rental-rates-gateway). Klaim kejelasan ketersediaan meningkatkan penyelesaian booking berasal dari vendor (Booqable blog di atas).
- Rekomendasi halaman booking harus dioptimalkan mobile dengan fungsi setara desktop [vendor-mkt] — [Peek Pro](https://www.peekpro.com/blog/rental-booking-page-example).
- Pesan layanan (service reply) dalam 24 jam setelah pelanggan memulai percakapan tidak ditagih di WhatsApp Business Platform [pihak-3] — [Message Central, Apr 2026](https://www.messagecentral.com/blog/whatsapp-business-api-pricing-2026); [Gupshup IDR Jan 2026](https://www.gupshup.ai/resources/wp-content/uploads/2025/12/IDR_Jan2026.pdf) (menyebut service messages tidak ditagih).
- Konteks Indonesia: pemesanan alat berat di rental kecil lazimnya lewat WhatsApp/telepon (disebut dalam latar skripsi HK Equipment di atas) — [UMS eprints](https://eprints.ums.ac.id/144968/).

### Inferences
- Karena bukti konversi lemah, urutan prioritas fase 1 sebaiknya berdasar biaya kecil dan kecocokan perilaku pasar: (1) tombol WhatsApp terpasang di semua halaman unit dengan teks pesan terisi (nama unit, lokasi, tanggal) via tautan `wa.me` (cara kerja standar WhatsApp; tidak diverifikasi di sesi ini); (2) RFQ pendek (nama, WA, unit, lokasi proyek, tanggal mulai, durasi) dan SLA respons; (3) halaman unit dengan spesifikasi dan unduhan brosur/PDF; (4) label ketersediaan sederhana ("Tersedia / Terbatas / Tanya") alih-alih kalender real-time, karena kalender real-time menuntut data inventori yang akurat dan disiplin pembaruan.
- Kalkulator tarif hanya masuk akal jika tarif tertulis dan stabil; biaya tambahan (mobilisasi, operator, BBM) umum di pasar sehingga estimasi bisa menyesatkan; lihat catatan `Pasar - Biaya tambahan di luar tarif.md` di vault.
- Live chat pihak ketiga kemungkinan tumpang tindih dengan WhatsApp; tidak ditemukan bukti yang membenarkannya sebagai prioritas.

### Gaps
- Tidak ada benchmark independen untuk tingkat konversi RFQ, jumlah kolom form optimal (Baymard/HubSpot tidak dicari), atau dampak kalender vs label ketersediaan pada rental alat berat.
- Tidak ada data perilaku kontraktor Indonesia (rasio WhatsApp vs form vs telepon).
- Bukti untuk perbandingan spesifikasi dan unduhan dokumen tidak ditemukan (tidak dicari terpisah).

## 3. Integrasi pembayaran dan komunikasi Indonesia

### Takeaway
Midtrans dan Xendit sama-sama tanpa biaya setup/bulanan dan menagih per transaksi sukses (VA sekitar Rp4.000 tetap; QRIS ~0,63–0,7%); angka perlu dikonfirmasi karena sumber bertentangan. Untuk B2B sewa alat berat bernilai jutaan hingga puluhan juta rupiah, transfer/VA dan invoice lebih relevan daripada kartu; pajak (PPN 12% dengan DPP nilai lain 11/12 sejak 2025, Coretax) menjadi pekerjaan back-office, bukan fitur website.

### Cited Findings
- **Midtrans**: biaya per transaksi sukses, tanpa biaya implementasi/pemeliharaan; contoh dokumentasi untuk bank transfer Rp4.000 pada penjualan Rp100.000 (ilustrasi, bukan tarif VA resmi); biaya belum termasuk PPN; tarif BCA dan Indomaret dinegosiasikan kasus per kasus [resmi-snippet] — [Midtrans: How much does Midtrans charge](https://docs.midtrans.com/docs/how-much-does-midtrans-charge-for-its-payment-service); [Midtrans pricing](https://docs.midtrans.com/docs/pricing).
- Midtrans QRIS: MDR 0,7% per transaksi sukses untuk merchant reguler; kategori merchant khusus perlu konfirmasi [resmi-snippet] — [Midtrans QRIS fee](https://docs.midtrans.com/docs/what-is-the-applicable-transaction-fee-for-qris).
- Tarif GoPay 2% dari artikel sekunder tak bertanggal; dianggap tidak terverifikasi — [DealPOS FAQ MDR](https://support.dealpos.com/en/articles/4774137-faq-mdr-payout).
- Tingkatan MDR QRIS Bank Indonesia (via Bank Mandiri): usaha mikro 0% untuk transaksi maksimum Rp100.000 dan 0,3% di atasnya (berlaku 1 Jul 2023); pendidikan 0,6%; SPBU/BLU/PSO 0,4% [pihak-3] — [Bank Mandiri QRIS](https://www.bankmandiri.co.id/qris).
- **Xendit**: tanpa biaya registrasi, langganan, atau pemeliharaan; VA aggregator tetap Rp4.000; switcher Rp2.000 + biaya bank (DBS Rp5.000 + biaya bank); QRIS 0,63% pada tabel lama vs 0,7% pada perbandingan pihak ketiga atas halaman Indonesia terkini (bertentangan); harga eksklusif PPN 11%, kecuali QRIS dan ShopeePay menurut halaman harga [resmi-snippet + pihak-3] — [Xendit help: pricing](https://help.xendit.co/hc/en-us/articles/360039086452-What-are-the-pricing-for-Xendit-products-); [Xendit pricing ID](https://xendit.co/en-id/pricing/); [Xendit fees and VAT](https://docs-dev.xendit.co/fees-and-vat); [Quasa perbandingan](https://quasa.io/id/media/xendit-vs-midtrans-biaya-tetap-rp4000-mengubah-pilihan-bisnis-kecil). Tidak ditemukan biaya khusus untuk fitur Invoice (diasumsikan memakai tarif metode yang dipilih; tidak diverifikasi).
- **PPN / Faktur Pajak**: tarif nominal 12% mulai 1 Jan 2025 (PMK 131/2024); untuk barang/jasa non-mewah, besaran pajak efektif tetap 11% lewat DPP Nilai Lain 11/12; faktur ber-11% ditoleransi sampai 31 Mar 2025, mulai 1 Apr 2025 faktur harus menampilkan 12% dengan DPP nilai lain; faktur pajak diterbitkan di modul e-Faktur pada Coretax (menu Pajak Keluaran) — [DDTCNews](https://news.ddtc.co.id/review/konsultasi-coretax/1808042/bagaimana-cara-membuat-faktur-pajak-dengan-dpp-nilai-lain-di-coretax); [DDTCNews: toleransi 11% hingga 31 Maret](https://news.ddtc.co.id/berita/nasional/1808108/jangan-bingung-faktur-pajak-masih-boleh-pakai-ppn-11-hingga-31-maret); [pajak.go.id](https://www.pajak.go.id/id/berita/wajib-pajak-datangi-kpp-sintang-untuk-pahami-aturan-ppn-terbaru). Sumber 2026 menyebut pemerintah meninjau perlakuan PPN skema DPP khusus lain; tidak ada hasil spesifik untuk jasa sewa alat berat.
- **WhatsApp Business Platform**: harga per pesan menurut kategori; kartu tarif Gupshup (Jan 2026, tertulis "bukan kartu tarif terkini"): Indonesia marketing Rp586,33, utility Rp356,65, authentication Rp356,65, authentication-international Rp1.940,13 per pesan; service message tidak ditagih [pihak-3] — [Gupshup IDR Jan 2026](https://www.gupshup.ai/resources/wp-content/uploads/2025/12/IDR_Jan2026.pdf). Message Central (Apr 2026): marketing Indonesia $0,0283 [pihak-3] — [Message Central](https://www.messagecentral.com/blog/whatsapp-business-api-pricing-2026). Qontak (Okt 2026) menyebut penagihan per pesan semua kategori mulai 1 Okt 2026, tetapi menyebutnya "simulasi"; tidak terverifikasi — [Qontak](https://help-center.qontak.com/hc/en-us/articles/48430892733465-Latest-WhatsApp-Message-Prices-October-2026). Halaman resmi Meta: [developers.facebook.com/docs/whatsapp/pricing](https://developers.facebook.com/docs/whatsapp/pricing) dan [halaman baru](https://developers.facebook.com/documentation/business-messaging/whatsapp/pricing) (isi tabel tarif tidak terbaca); changelog Meta mencatat billing lokal India (Jan 2026) dan Brasil (paruh kedua 2026), tanpa menyebut Indonesia.
- **BSP WhatsApp di Indonesia** (penyedia resmi Meta): Qontak/Mekari (klaim 3.500+ klien atau 20.000+ bisnis; sumber berbeda), Qiscus, Barantum, Maxchat, SleekFlow, Infobip, Twilio, Telin; perkiraan harga langganan platform dari satu perbandingan: Barantum ~$50/bln, Maxchat ~$48/bln (5 agen), Qiscus mulai $115/bln; Qontak berbasis kuotasi [vendor-mkt] — [Qontak BSP](https://qontak.com/en/features/whatsapp-bsp/); [Qiscus: 15 BSP](https://www.qiscus.com/id/blog/whatsapp-business-solution-provider/); [Qiscus: WhatsApp Partner](https://www.qiscus.com/id/blog/whatsapp-partner-indonesia/); [AiSensy](https://m.aisensy.com/blog/best-whatsapp-api-providers-indonesia/); [Telin](https://telin.net/en/company/news/telin-become-a-telecom-whatsapp-business-solution-provider-bsp). Saran vendor: pilih BSP resmi untuk menghindari pemblokiran nomor; reseller non-resmi berisiko putus mendadak. Status Fonnte dan Wati sebagai BSP resmi tidak terkonfirmasi.
- **Peta**: repo sudah memuat `leaflet` ^1.9.4 dan `react-leaflet` ^5.0.0 (diverifikasi dari package.json). Tidak ada sumber eksternal untuk Google Maps/Leaflet dibaca di sesi ini.

### Inferences
- Fase 1 tidak membutuhkan payment gateway: transaksi sewa alat berat umumnya lewat penawaran, kontrak, DP, dan invoice berbasis transfer bank. Gateway (Midtrans/Xendit) baru berguna untuk tautan bayar DP/invoice (payment link/invoice VA) pada fase 2. Biaya VA Rp4.000 tetap menguntungkan untuk nominal besar; MDR persentase (QRIS/kartu) lebih mahal untuk nominal besar.
- Rekonsiliasi e-Faktur/Coretax kemungkinan dikerjakan di perangkat akuntansi (bukan di website); website cukup mengumpulkan NPWP/nama perusahaan pada RFQ agar penerbitan faktur lancar.
- WhatsApp "click-to-chat" gratis; WhatsApp Business Platform (API) baru perlu bila ada otomatisasi, banyak agen, atau pengingat jatuh tempo. Template utility ~Rp357/pesan menjadikan pengingat kontrak/invoice murah relatif terhadap nilai transaksi.
- Leaflet (gratis, sudah ada di repo) cukup untuk peta area layanan; Google Maps hanya bila butuh Places/geocoding/routing dan siap menanggung biaya API (tidak diverifikasi).

### Gaps
- Halaman resmi Midtrans dan Xendit tidak terbaca (diblokir); tarif VA per bank, kartu, GoPay/ShopeePay terkini tidak terverifikasi.
- Tarif resmi WhatsApp Meta untuk Indonesia 2026 tidak terbaca; tarif dari reseller bisa berbeda dari tarif Meta.
- Tidak ada konfirmasi PPN/e-Faktur khusus jasa sewa alat berat (sewa tanpa/dengan operator, PPh 23 atas sewa); perlu konsultan pajak.
- Tidak mencari: e-materai untuk kontrak digital, penyedia e-sign Indonesia (PrivyID, Peruri, VIDA), harga Google Maps Platform.

## 4. Opsi stack teknis: SSG/SSR, headless CMS, WordPress/WooCommerce, vs repo React 19 + Vite 8 + Tailwind 4

### Takeaway
Untuk situs katalog/RFQ yang harus muncul di Google, HTML harus sudah berisi konten saat dikirim: SSG/SSR (Astro, Next.js, Nuxt) atau prerender memenuhi itu. SPA Vite murni berisiko SEO; di ekosistem repo ada dua jalur yang terdokumentasi, yakni React Router v7 framework mode dengan `prerender` dan Vike (SSR/SSG di atas Vite). WordPress/WooCommerce tetap opsi tercepat dan termurah, dengan risiko performa mobile bergantung plugin dan tema.

### Cited Findings
- Google tidak lagi merekomendasikan dynamic rendering (hanya workaround); sumber memberi tanggal berbeda (2022/2024/2025) dan semuanya bukan dokumen Google sendiri; rekomendasi umum: SSR/SSG untuk konten yang harus di-rank, CSR untuk area login/interaktif. Googlebot menjalankan Chrome headless mutakhir namun pengindeksan konten JS bisa tertunda; JSON-LD sebaiknya dikirim dari server. Klaim blog vendor bahwa GPTBot/ClaudeBot/PerplexityBot tidak merender JS belum diverifikasi [pihak-3] — [Search Engine Land](https://searchengineland.com/google-no-longer-recommends-using-dynamic-rendering-for-google-search-387054); [BlckAlpaca](https://blckalpaca.at/en/knowledge-base/seo-geo/technical-seo/javascript-seo-rendering-and-indexing).
- **React Router v7** (repo sudah memakai `react-router-dom` ^7.18): opsi `prerender` di `react-router.config.ts` menerima `true`, daftar path, atau fungsi async (misal ambil path dari CMS); dengan `ssr:true` (default) halaman diprerender di samping server runtime, dengan `ssr:false` hasilnya statis untuk static host; `ssr:false` tanpa `prerender` = "SPA Mode" yang hanya merender route root; loader yang sama dipakai. Dokumentasi diverifikasi hingga versi 7.9.3 pada hasil pencarian; halaman versi terbaru tidak terbaca [resmi-snippet] — [React Router pre-rendering 7.9.3](https://reactrouter.com/7.9.3/how-to/pre-rendering.md); [7.7.0](https://reactrouter.com/7.7.0/how-to/pre-rendering). Catatan: itu mode "framework" (plugin Vite `@react-router/dev`), berbeda dari pemakaian `react-router-dom` saat ini di repo (mode library); migrasi perlu dikerjakan (inferensi dari dokumentasi).
- **Vike** (dulu vite-plugin-ssr): mendukung SPA, SSR, dan pra-render SSG; dapat ditambahkan ke aplikasi Vite yang ada via `vite.config`; route dinamis butuh hook `prerender()` yang mengembalikan daftar URL; satu isu lama (v0.4.x) melaporkan kegagalan prerender dengan TanStack Query prefetch [resmi-snippet] — [Vike: add to existing Vite app](https://vike.dev/add); [Vike pre-rendering](https://vike.dev/pre-rendering); [SPA vs SSR](https://vite-plugin-ssr.com/SPA-vs-SSR); [prerender hook](https://vite-plugin-ssr.com/prerender); [diskusi #774](https://github.com/vikejs/vike/discussions/774).
- **Astro**: Astro 6.0 dirilis 10 Mar 2026 (dev server baru, kompiler Rust eksperimental, live content collections, CSP); 6.1 menambahkan default Sharp per-codec dan fallback i18n [resmi-snippet] — [Astro RSS](https://astro.build/rss.xml); [Astro Jan 2026 update](https://astro.build/blog/whats-new-january-2026/); [Netlify/Astro 6](https://blogs.apievangelist.com/blogs/netlify-2026-03-10-astro-6-just-works-on-netlify/). Tidak ditemukan benchmark independen Astro vs Next.js.
- **Headless CMS** (semua dari agregator [pihak-3]): Sanity (SaaS, free tier ~20 seat, 10.000 dokumen, 250.000 API request/bln; berbayar mulai ~$15/seat), Strapi (open source self-host; Cloud $18 atau $29/bln, sumber berbeda), Payload (self-host gratis; Cloud $35/$199), Directus (self-host; Cloud mulai $99/bln; source-available; gratis untuk organisasi <$5M pendapatan dan <50 karyawan menurut satu sumber), Contentful (tanpa free tier komersial, Lite mulai $300/bln) — [Directus: best headless CMS 2026](https://directus.com/resources/best-headless-cms-in-2026); [ColorWhistle](https://colorwhistle.com/sanity-contentful-payload/); [G2 Payload](https://g2.com/products/payload-cms/pricing); [Dupple](https://dupple.com/learn/best-headless-cms). Heuristik satu blog: self-host layak dievaluasi saat biaya SaaS > ~$400–600/bln.
- **WordPress/WooCommerce**: tersedia plugin rental gratis dan berbayar (lihat bagian 1); tidak ditemukan sumber pembanding performa vs Next.js.
- **Core Web Vitals** (ambang web.dev, persentil ke-75): LCP baik <=2,5 detik (buruk >4 detik), INP <=200 ms (buruk >500 ms), CLS <=0,1 (buruk >0,25) [resmi-snippet] — [web.dev thresholds](https://web.dev/articles/defining-core-web-vitals-thresholds); data Google dikumpulkan dari pengguna Chrome nyata 28 hari terakhir [pihak-3] — [corewebvitals.io](https://corewebvitals.io/core-web-vitals).
- **CDN/hosting Indonesia**: Cloudflare punya PoP di NTT Indonesia Nexcenter (Jakarta) dan Yogyakarta (CitranetIX), peering di 3 IX lokal, serta link 100G ke Singapura; tiga ISP terbesar (Telkom, Indosat Ooredoo Hutchison, XL Axiata) menguasai ~80% pasar dan, menurut Cloudflare, rute lintas jaringan luar negeri memperbesar latensi [resmi-snippet] — [Cloudflare blog: Indonesia](https://blog.cloudflare.com/indonesia/). Tidak ada pengukuran latensi/kecepatan mobile Indonesia terkini yang ditemukan (benchmark Cloudflare 2021 sudah usang).

### Inferences
- Rekomendasi sementara berdasar bukti: (a) jika tim sudah kuat di React/TypeScript dan ingin satu bahasa dengan repo: React Router v7 framework mode (prerender) atau Astro dengan island React untuk bagian interaktif (RFQ, filter); (b) bila tim non-teknis butuh CMS cepat dan anggaran minimal: WordPress + tema ringan + plugin RFQ/WhatsApp, dengan disiplin plugin untuk menjaga CWV. Astro lebih sesuai untuk situs dominan konten (inferensi dari model islands, tidak ada benchmark yang ditemukan).
- Vite SPA murni (seperti repo QSHE saat ini) tidak disarankan untuk halaman publik yang harus diindeks; boleh dipakai untuk portal pelanggan/admin di belakang login, yang tidak butuh SEO.
- Jika memilih headless CMS untuk tim kecil: Sanity (free tier) atau Payload/Strapi self-host; biaya self-host ditentukan server dan perawatan, bukan lisensi.
- Gunakan Cloudflare di depan situs (cache HTML statis, gambar AVIF/WebP via format modern, ukuran responsif); hosting statis (Cloudflare Pages, Netlify, Vercel) dengan edge Jakarta/Singapura mengurangi latensi (klaim region spesifik tiap host tidak diverifikasi).

### Gaps
- Dokumentasi resmi Next.js, Nuxt, Astro, Vite, web.dev (diblokir), dan dokumen Google Search Central tentang JavaScript SEO tidak dibaca langsung.
- Tidak ada data performa nyata WordPress vs SSG pada jaringan mobile Indonesia; tidak ada angka CrUX Indonesia.
- Tidak diverifikasi: dukungan resmi React Router v7 `prerender` pada versi 7.18 (hanya sampai 7.9.3 terlihat), kompatibilitas Vite 8 dengan Vike/Astro 6 (Astro 6 menurut satu sumber memakai Vite 7), dan kompatibilitas React Compiler dengan prerender.
- Harga hosting Indonesia (Biznet Gio, Niagahoster, IDCloudHost) dan opsi data residency (UU PDP) tidak dicari.

## 5. Telematika/IoT (GPS, hour-meter) sebagai pembeda

### Takeaway
Telematika ada dalam dua bentuk: platform OEM/agregator multi-merek (Trackunit, Komtrax, Product Link) yang harganya tidak dipublikasikan, dan GPS tracker retrofit lokal berharga ratusan ribu hingga jutaan rupiah per unit; bukti harga terkini minim. Untuk fase 1 website, telematika realistisnya hanya sebagai klaim/halaman informasi ("unit dilengkapi GPS"), bukan integrasi data langsung.

### Cited Findings
- **Trackunit**: harga disesuaikan untuk armada rental dan kontraktor; harga per aset turun seiring ukuran armada; satu review menyebut model per aset terhubung per bulan, perangkat dibeli atau termasuk tergantung kontrak; tidak ada harga publik [resmi + pihak-3] — [Trackunit pricing](https://trackunit.com/?p=31921); [Software Advice](https://www.softwareadvice.com/construction/trackunit-profile/).
- **Komatsu Komtrax**: terpasang standar pada unit baru Komatsu menurut satu perusahaan rental; dapat dipasang retrofit pada unit lama atau merek lain dengan sistem listrik 12V/24V; tanpa harga di sumber — [Mining Weekly, 2018](https://www.miningweekly.com/article/komtrax-provides-the-key-for-top-class-rental-management-2018-08-13).
- **Caterpillar Product Link**: tidak ada hasil relevan (biaya/API tidak ditemukan).
- **Lokal Indonesia**: StartGPS S910 (PT Sinergi Teknologi Terpadu Indonesia, diluncurkan Nov 2021) dapat dipasang pada mobil dan alat berat (excavator, traktor), memantau konsumsi BBM real-time dan dapat dibandingkan dengan jam kerja/hour meter; satu sumber menyebut harga Rp1.599.000 (data 2021, belum termasuk pemasangan/langganan) — [Merdeka.com](https://www.merdeka.com/otomotif/startgps-luncurkan-dua-produk-baru-keren-bisa-pantau-konsumsi-bbm-realtime.html); [Otodriver](https://otodriver.com/berita/2021/startgps-luncurkan-gps-yang-bisa-pantau-bbm-realtime-stacfiiaime); [Mobil123](https://www.mobil123.com/berita/ada-gps-tracker-yang-bisa-pantau-konsumsi-bbm-dari-jauh-lho/64716/amp/). PT. Digital (Banten) mengiklankan IoT/GPS kustom untuk excavator, dozer, dump truck, kran (2026, promosi, tanpa harga) — [romisaputra.com, Mar 2026](https://www.romisaputra.com/2026/03/rekomendasi-custom-gps-tracker-dari-pt-digital-ini-kelebihannya.html). Studi akademik: aplikasi pelacakan alat berat tambang berbasis Android + MySQL — [UNAJA e-journal](https://ejournal.unaja.ac.id/index.php/JVT/article/view/1051/771).
- Preseden pemerintah: rencana Kementan 2019 memasang GPS tracking dan dashboard pada traktor/excavator bantuan — [Warta Ekonomi](https://wartaekonomi.co.id/read213327/kementan-hadirkan-gps-tracking-untuk-lacak-alat-mesin-pertanian).

### Inferences
- Integrasi telematika (API OEM) memerlukan kontrak, perangkat di tiap unit, dan pemeliharaan data; tidak realistis untuk fase 1 website. Jalur bertahap: fase 1 menyebut GPS/hour-meter di spesifikasi unit atau layanan; fase 2 laporan jam kerja manual/foto hour-meter ke pelanggan; fase 3 dashboard bila ada penyedia dengan API (konfirmasi).
- Karena merek di pasar Indonesia beragam, platform multi-merek (retrofit) lebih cocok daripada Komtrax/Product Link yang terikat OEM (inferensi; ketersediaan API tidak diverifikasi).

### Gaps
- Tidak ada harga terkini perangkat, pemasangan, dan langganan telematika di Indonesia; tidak ada harga Trackunit/Komtrax/Product Link/EquipmentShare (EquipmentShare tidak dicari).
- Tidak ada bukti bahwa telematika menaikkan konversi atau ditanyakan oleh penyewa Indonesia.
- Tidak diverifikasi akses API bagi rental kecil, kebutuhan SIM/kuota data, dan keandalan sinyal di lokasi proyek terpencil.
